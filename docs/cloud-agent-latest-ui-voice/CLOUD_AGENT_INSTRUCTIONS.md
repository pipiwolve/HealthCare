# 云端 Agent 完整执行指令

你正在维护一个 Taro 4 + React + TypeScript 微信小程序。请应用同目录下的 `0001-latest-ui-voice.patch`，同步本地当前实现，并完成代码检查、微信小程序构建和语音输入回归验收。不得只回复“已修复”，必须逐项说明补丁状态、构建结果和语音 UI 验收结果。

## 一、应用补丁

先检查云端工作区状态和补丁是否已应用：

```bash
rtk git status --short
rtk git apply --check docs/cloud-agent-latest-ui-voice/0001-latest-ui-voice.patch
rtk git apply --check --reverse docs/cloud-agent-latest-ui-voice/0001-latest-ui-voice.patch
```

- 正向检查通过时，执行 `rtk git apply docs/cloud-agent-latest-ui-voice/0001-latest-ui-voice.patch`。
- 反向检查通过时，说明补丁已经存在，不要重复应用，直接验收。
- 两者都不通过时，使用 `rtk git apply --3way ...`，保留云端已有的 BLE、RTC、TTS、图片、历史记录和登录能力，逐文件解决冲突。
- 禁止使用 `git reset --hard`、`git checkout -- <file>` 或整文件覆盖处理冲突。

## 二、必须达到的页面结果

### 健康档案

- 昵称输入框宽度为 `160px`，右侧位置保持不变，向左延长到设计标记位置。
- 年龄、身高、体重输入框保持当前已验收尺寸，不得再次改成长输入框。
- 年龄、身高、体重的单位区域保持固定宽度，三行输入框左、右边缘对齐，不能因为 `cm` 比 `岁` 宽而出现凸出。
- 常见药物快捷选项和手动添加药物功能必须保留，`medications` 继续使用现有字符串字段，不新增数据库迁移。
- 个人健康档案和家庭成员编辑页都要提供二甲双胍、胰岛素、阿卡波糖、氨氯地平、阿托伐他汀、华法林快捷选项，以及“其他药物”输入和添加按钮。

### 个人页与注册

- 个人页“退出登录”按钮使用绿色文字、绿色边框和白色背景，不得恢复红色危险按钮样式。
- 注册密码只校验 `6-72` 位，不要求必须包含英文字母；纯数字 6 位密码必须通过前端校验。
- 注册密码输入框提示为“请输入6-72位密码”，保留确认密码和现有验证码流程。

### AI 问答语音模式

- 文字模式保留麦克风切换按钮、文本输入框和发送按钮。
- 用户第一次点击文字模式的麦克风切换按钮时，必须立即预检查并申请 `scope.record`，不得等到第一次长按“按住说话”后才弹出授权窗口。
- 已授权时切换语音模式不得重复弹窗；切换和紧接着的长按必须复用同一个权限请求，不能并发调用两次 `Taro.authorize`。长按录音处仍保留权限复查，以兼容用户后来从系统设置撤销权限。
- 切换到语音模式后，只允许显示两个交互区域：左侧键盘切换按钮，以及中央“按住说话”区域。
- 语音模式右侧不得出现圆形麦克风按钮，也不得出现机器人、电话或实时通话入口。
- 中央“按住说话”区域的默认态和录音态都不得再渲染麦克风图标；录音状态只显示文字和波形反馈。
- 不得恢复旧的 `handleVoiceMicToggle`、实时语音通话按钮或第三个右侧按钮。
- 保留现有 `voice-ptt` 独立 ASR WebSocket、500ms 最短录音、上滑取消、松开停止、重复录音隔离、AI 回复中断、RTC TTS 和语音消息播放逻辑。
- 录音控件状态必须与 ASR、上传和 AI 回复解耦：松手时立即调用 `RecorderManager.stop()`，同时立即恢复白色“按住说话”，不得继续显示红色“正在发送...”。
- `touchcancel` 与 `touchend` 可能连续到达，停止逻辑必须幂等；已经完成的 `onStop` 不得被旧的 React 状态再次覆盖成录音中或发送中。
- `RecorderManager.onStop` 返回后，在消息列表显示“正在识别...”，识别和 AI 回复继续异步执行，不得锁住底部录音按钮。
- 如果权限弹窗期间已经松手，不得在授权结束后重新开始录音；如果 `RecorderManager.onStop` 没有及时回调，必须在 3 秒内清理内部录音状态并提示“录音停止超时，请重试”，旧录音回调不得再次发送消息。

## 四、人工验收

1. 打开个人资料页，确认昵称框比年龄/身高/体重框更长，但年龄、身高、体重三项尺寸和对齐不变。
2. 确认主档案和家庭成员编辑页都可以快捷选择及手动添加药物。
3. 确认退出登录按钮为绿色文字白底，注册时 `123456` 可以通过密码规则校验。
4. 首次进入 AI 问答并点击文字输入框旁的麦克风切换按钮，确认此时就弹出麦克风授权；同意后再长按“按住说话”，录音立即开始且不再弹窗中断。
5. 再次切换语音模式时确认已授权用户不重复弹窗；底部只有左侧键盘按钮和中央“按住说话”区域，右侧没有任何圆形按钮，中央区域内没有麦克风图标。
6. 按住超过 500ms 后松开，确认底部按钮立刻恢复白色“按住说话”，消息列表显示“正在识别...”并在识别完成后自动发送，不得出现持续的红色“正在发送...”。
7. 连续验证正常松手、上滑取消、首次权限弹窗期间松手、快速触发 `touchcancel` + `touchend`，确认每次只停止和发送一次，且下一次长按无需额外点击即可直接录音。
