# 云端 Agent 更新指令

请将本补丁应用到与当前小程序相同的前端代码库，并完成以下验收。

## 变更内容

1. 营养分析 JSON 和 Markdown 总览新增 `sugar` 糖分字段，单位为克。优先估算添加糖或游离糖；无法区分时，明确标注为总糖估算。
2. 对健康档案中慢性病包含糖尿病的用餐成员，按本次整餐糖分除以用餐人数计算人均值。超过 25 克时显示居中健康预警，并提供“我知道了”关闭按钮。
3. `25 克/天`只作为添加糖/游离糖的通用参考上限，不能表述为所有糖尿病患者的固定医嘱；提醒用户结合医生或营养师建议。
4. 营养总览和兜底分析结果都要显示糖分整餐总量及人均值。
5. 所有 AI Markdown 输出面板去除结构性冒号和孤立冒号行。不要让冒号单独占一行；代码块中的 JSON、网址和时间格式不能被破坏。
6. 过敏源提示继续使用页面中心弹窗，点击“我知道了”关闭，不要恢复顶部红色条。

## 约束

- 不新增未部署的数据库字段，避免云端数据库 schema 尚未迁移时导致称重记录保存失败。
- 普通成员或没有糖尿病健康档案的成员不触发糖分预警。
- 多名用餐成员时使用人均糖分判断，不能直接拿整餐总糖分与阈值比较。
- 不恢复语音模式中的麦克风图标。
- 维持现有微信快捷登录逻辑，不强制首次微信登录绑定邮箱。

## 验收命令

```bash
pnpm exec tsc --noEmit -p tsconfig.check.json
pnpm lint
node scripts/checkWechatFeatures.mjs
node scripts/checkDeviceTestFixes.mjs
node scripts/checkChatStreaming.mjs
pnpm build:weapp
```

请额外验证：糖尿病成员本次人均糖分 `30g` 时弹窗出现，普通成员或人均 `25g` 及以下时不弹窗；Markdown 中的 `：` 或 `:` 不会单独渲染成一行。
